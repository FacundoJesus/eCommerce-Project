# 🛒 E-Commerce Full Stack

Este proyecto es una aplicación de comercio electrónico desarrollada como parte de mi aprendizaje en **Java Full Stack Development**, utilizando **Spring Boot** para el backend y **React** para el frontend.

El objetivo del proyecto fue construir una aplicación **full stack de nivel productivo**, aplicando buenas prácticas de desarrollo, arquitectura en capas y tecnologías ampliamente utilizadas en el ecosistema Java.

## 🚀 Tecnologías utilizadas

### Backend

* Java
* Spring Boot
* Spring Security
* JWT (JSON Web Tokens)
* Spring Data JPA / Hibernate
* Maven
* Lombok
* PostgreSQL / MySQL
* REST API

### Frontend

* React
* JavaScript (ES6+)
* React Router
* React Hooks
* Context API
* Redux
* Tailwind CSS
* Axios

## ✨ Funcionalidades principales

* Registro e inicio de sesión de usuarios.
* Autenticación y autorización mediante JWT.
* Gestión de roles y permisos.
* Administración de categorías y productos.
* Búsqueda, paginación y ordenamiento de productos.
* Carrito de compras.
* Gestión de direcciones de envío.
* Creación y administración de pedidos.
* Validación de datos.
* Persistencia con JPA/Hibernate.
* API REST desacoplada consumida desde React.

## 📚 Objetivos del proyecto

Este proyecto fue desarrollado siguiendo un curso completo de **Spring Boot Full Stack** y posteriormente adaptado y puesto en práctica para consolidar conocimientos sobre:

* Desarrollo de APIs REST con Spring Boot.
* Arquitectura de aplicaciones Java.
* Seguridad con Spring Security y JWT.
* Persistencia de datos con JPA/Hibernate.
* Desarrollo de interfaces modernas con React.
* Comunicación entre frontend y backend.
* Buenas prácticas para aplicaciones Full Stack.

## 🎯 Aprendizajes

Durante el desarrollo adquirí experiencia práctica en la construcción de una aplicación completa de eCommerce, comprendiendo el flujo completo desde la base de datos hasta la interfaz de usuario, incluyendo autenticación, autorización, gestión de entidades, consumo de APIs y desarrollo de una arquitectura desacoplada.

Este proyecto representa uno de mis principales trabajos de aprendizaje en el ecosistema **Java + Spring Boot + React** y sirve como base para continuar profundizando en arquitecturas más avanzadas, como microservicios, despliegue en la nube y aplicaciones empresariales.
